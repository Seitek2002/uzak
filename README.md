# Узак Өмүр

Бесплатный онлайн-тест здоровья и долголетия для пользователей из любой страны (по мотивам kamalama.org). 38 вопросов (34, если пропустить анализы крови), около семи минут, без регистрации. Отчёт: прогноз, сравнение со сверстниками своей страны, потенциал, биологический возраст, карта из 34 факторов, с чего начать, что обсудить с врачом и все ответы с возможностью изменить любой. Ответы хранятся только в браузере (localStorage, ключ `uzak-v1`, версия 2; первая версия переносится автоматически).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3100
npm run build && npm run start
npm run typecheck
npm run test:model   # защита модели от поломок (63 проверки)
npm run model:print  # прогнозы для типовых профилей и диапазоны факторов
npm run test:e2e     # сценарии в браузере, нужен запущенный сайт и Playwright
npm run life-tables  # обновить таблицы, профили стран и названия (раз в год)
```

## Публикация

Сайт: https://seitek2002.github.io/uzak/. Каждый пуш в `main` запускает `.github/workflows/pages.yml`: проверка модели, статическая сборка (`GITHUB_PAGES=true`, подпапка `/<репозиторий>`) и выкладка в ветку `gh-pages`, которую раздаёт GitHub Pages. Скрипт `scripts/flatten-segments.mjs` дописывает файлы предзагрузки страниц, которые Next.js 16 при статическом экспорте кладёт не под теми именами.

Собрать ту же копию локально (в Git Bash добавьте `MSYS_NO_PATHCONV=1`, иначе путь `/uzak` превратится в путь Windows):

```bash
GITHUB_PAGES=true NEXT_PUBLIC_BASE_PATH=/uzak npm run build && node scripts/flatten-segments.mjs out
```

`test:e2e` берёт Playwright из проекта (`npm i -D playwright`) или из папки `PLAYWRIGHT_DIR` и запускает установленный Chrome. Переменная `NEXT_PUBLIC_SITE_URL` задаёт адрес сайта для sitemap, robots и Open Graph.

## Стек

Next.js 16 (App Router, всё статически пререндерится), React 19, TypeScript, Zustand (persist), чистый CSS на токенах. Дизайн: Hallmark, тема Grid (бумага, тушь, ультрамарин, один швейцарский красный), шрифты Wix Madefor Display и Text с кириллицей.

## Вопросы

Темы повторяют факторы теста kamalama.org, плюс силовые упражнения и сладкие напитки. Формулировки, варианты и тексты свои, без привязки к одной стране: ммоль/л и мг/дл рядом, рост и вес в метрических единицах или в футах и фунтах, служба спасения без единственного номера. Страна за последние 10 лет подставляется по IP-адресу (`shared/lib/country-by-ip.ts`: api.country.is, запасной get.geojs.io), её можно сменить. Перед анализами крови есть развилка: без результатов четыре вопроса пропускаются.

## Тест для питомцев

Кнопка «Пройти тест» в шапке ведёт на `/start`: выбор «Себя» или «Питомца». Тест для кошки или собаки живёт на `/pet/test` (15 вопросов для кошки, 16 для собаки), отчёт на `/pet/report`, описание факторов и источники на `/pet`. Ответы хранятся отдельно (localStorage, ключ `uzak-pet-v1`), история проверок общая для всех питомцев.

| Путь | Что там |
| --- | --- |
| `src/entities/pet/model/factors.ts` | Вопросы, варианты и отношения рисков для кошек и собак |
| `src/entities/pet/model/engine.ts` | Модель Гомперца–Мейкхема по группам (кошки, собаки четырёх размеров), калибровка по когортам, возраст по-человечески |
| `src/entities/pet/model/content.ts` | Тексты страницы `/pet` и источники |
| `src/features/pet-quiz`, `src/features/pet-report` | Вопросник и отчёт |

Проверка модели питомцев: `npm run test:pet`.

## Модель

1. **Исходная кривая**: таблица смертности ВОЗ за 2023 год (сглажена, после 85 продолжена по наклону Гомперца). Для 35 стран с годом войны, бедствия, спада или сломанной кривой по возрастам взят 2019 год, правило записано в `scripts/life-tables.mjs`. Прошлая и будущая страны смешиваются: прошлая весит половину в начале и уходит за 15 лет.
2. **Прогресс**: будущая смертность снижается на 1% в год во всех странах. Это допущение.
3. **Ответы**: каждый вариант несёт отношение рисков смертности от всех причин из метаанализа. Похожие факторы объединены в кластеры (тренированность, тело, питание, отношения и настроение, сахар): сильнейший эффект идёт целиком, остальные на 50, 30, 20 и 10%. Изменяемые факторы проходят мягкий потолок, наследственность и диагнозы добавляются поверх.
4. **Сверстники**: итог сравнивается со средним риском людей того же пола и возраста в стране пользователя. Семь групп показателей взяты у ВОЗ по странам, остальные доли повторяют образец Кыргызстана и для других стран приблизительны. Где у страны нет показателя, стоит медиана региона ВОЗ.
5. **Возраст**: относительные риски полные до 55 лет и слабеют вдвое к 80 (курение и вес в старости влияют слабее).
6. **Дорога и мотоцикл**: постоянная добавка к годовому риску за вычетом средней, с поправкой на смертность на дорогах страны.

Национальная статистика может отличаться от ВОЗ. Пример: в Кыргызстане таблицы за 2023 год совпадают в 30–69 лет (до 8%), а с 70 национальная даёт смертность выше у мужчин в 2,6–4,5 раза, с 75 у женщин примерно в 1,8 раза. Причина не установлена, наш прогноз оптимистичнее национального.

Отношения рисков взяты из публикаций (`sources.ts`), пересчитаны под варианты ответов или оценены. Полной сверки с текстами статей и врачебной проверки не было. Распространённость взята из опроса ВОЗ STEPS 2023 по Кыргызстану, переписи 2022 года, данных о дорогах и GLOBOCAN. Где данных нет, доли оценены и помечены `estimate` в коде.

## Что проверить перед запуском

1. **Вычитка врачом или эпидемиологом**: отношения рисков в `factors.ts`, особенно новые вопросы (рак, анализы, мышечная сила, отношения) и бездымный табак.
2. **Доли с пометкой `estimate`** в `population.ts`: сон, шаги, силовые, переработанное мясо, анализы, СРБ, омега-3, настроение. Заменить, если появятся местные данные.
3. **Тексты** страниц факторов пересказывают выводы исследований своими словами. Перед публикацией сверить с источниками.
4. **Службы спасения**: на страницах «Напряжение» и «Это не диагноз» названы 112, 911 и 103 как примеры.
5. Название «Узак Өмүр» рабочее: меняется в `src/shared/config/site.ts`.

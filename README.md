# Узак Өмүр

Бесплатный онлайн-тест здоровья и долголетия для пользователей из любой страны (по мотивам kamalama.org), на русском, английском и кыргызском. 38 вопросов (34, если пропустить анализы крови), около семи минут, без регистрации. Отчёт: прогноз, сравнение со сверстниками своей страны, потенциал, биологический возраст, карта из 34 факторов, с чего начать, что обсудить с врачом и все ответы с возможностью изменить любой. Ответы хранятся только в браузере (localStorage, ключ `uzak-v1`, версия 2; первая версия переносится автоматически).

## Запуск

```bash
npm install
npm run dev          # http://localhost:3100
npm run build && npm run start
npm run typecheck
npm run test:model   # защита модели от поломок (проверок: 64)
npm run model:print  # прогнозы для типовых профилей и диапазоны факторов
npm run test:e2e     # сценарии в браузере, нужен запущенный сайт и Playwright
npm run i18n:check   # все ли тексты переведены
npm run test:e2e:locales # три языка, нужна собранная статическая копия (см. ниже)
node scripts/landing-shots.mjs # переснять экраны для лендинга на трёх языках (нужна она же)
npm run life-tables  # обновить таблицы, профили стран и названия (раз в год)
```

## Публикация

Сайт: https://seitek2002.github.io/uzak/. Каждый пуш в `main` запускает `.github/workflows/pages.yml`: проверка моделей и переводов, статическая сборка трёх языков (`/<репозиторий>/`, `/<репозиторий>/en/`, `/<репозиторий>/ky/`) и выкладка в ветку `gh-pages`, которую раздаёт GitHub Pages. Скрипт `scripts/flatten-segments.mjs` дописывает файлы предзагрузки страниц, которые Next.js 16 при статическом экспорте кладёт не под теми именами.

Собрать ту же копию локально (в Git Bash добавьте `MSYS_NO_PATHCONV=1`, иначе путь `/uzak` превратится в путь Windows):

```bash
NEXT_PUBLIC_BASE_PATH=/uzak NEXT_PUBLIC_SITE_URL=https://seitek2002.github.io/uzak npm run build:pages
```

`test:e2e` берёт Playwright из проекта (`npm i -D playwright`) или из папки `PLAYWRIGHT_DIR` и запускает установленный Chrome. Переменная `NEXT_PUBLIC_SITE_URL` задаёт адрес сайта для sitemap, robots и Open Graph.

## Стек

Next.js 16 (App Router, всё статически пререндерится), React 19, TypeScript, Zustand (persist), чистый CSS на токенах. Дизайн: Hallmark, тема Grid (бумага, тушь, ультрамарин, один швейцарский красный), шрифты Wix Madefor Display и Text. В них нет букв ө, ү, ң, поэтому кыргызская версия и кириллический логотип набраны шрифтом Onest.

## Языки

Исходный язык русский. Переводы лежат в `i18n/en.json` и `i18n/ky.json`, ключом служит хеш русского текста. `scripts/i18n/build.mjs` собирает три статические копии, словарей в браузере нет. `npm run dev` и `npm run build` дают только русскую версию.

1. Поменяли русский текст: `npm run i18n:extract`, затем добавьте перевод под новым ключом в оба словаря.
2. `npm run i18n:check` и `npm run build:pages` не пропустят текст без перевода, публикация тоже остановится.
3. Первый визит на русский адрес ведёт на язык браузера: ky на кыргызский, ru, be, kk, tg, uz на русский, остальные на английский. Выбор в переключателе запоминается (`uzak-lang`), ответы общие для всех языков.

Оба перевода сделаны машинно (ИИ). Английский вычитан тем же способом, кыргызский выборочно. Носитель не проверял ни один, на кыргызской версии об этом написано в подвале.

## Бонусные годы

Игровой слой поверх отчёта (`src/features/quests`), первая версия для людей:
- три изменения из «С чего начать» можно пройти как квест на 21 день: человек сам отмечает дни, растёт серия;
- после 21 отметки новый ответ записывается в отчёт новой попыткой, а годы, которые модель даёт за него, ложатся в «банк». Это та же оценка, что в отчёте, а не обещание. Курящий после квеста отвечает «бросил(а) меньше 10 лет назад», а не «10+ лет»;
- измеряемые показатели (вес, давление, пульс, сила, анализы) от отметок не меняются: квест заканчивается просьбой перемерить и обновить ответ;
- восемь значков в отчёте и плашка «Блок пройден» в тесте за каждый блок вопросов. Награда за пройденный блок, а не за «хороший» ответ, чтобы не подталкивать к неправде;
- всё хранится в браузере (`uzak-game-v1`), кнопка «Удалить мои ответы» стирает и квесты.

Проверки: `npm run test:game` (логика дней, серий, целей и лет), `npm run test:e2e:game` (сценарии в браузере).

## Стили прохождения

Перед первым вопросом новой попытки `/test` спрашивает, как проходить тест: три закрытые карты «Стиль 1», «Стиль 2», «Стиль 3» раскрываются после выбора, рядом «Обычная анкета без сюрпризов». Вопросы, ответы, модель и отчёт везде общие (`src/features/quiz/model/flow.ts` ведёт шаги и адресную строку для всех стилей). Правка ответа из отчёта всегда открывается обычной анкетой. Стиль и звук хранятся в `uzak-v1` и сбрасываются на новой попытке. Каждый стиль грузится отдельным куском только после выбора.

- **Стиль 1, «Путь героя»** (`src/features/journey`). Сначала создание героя (имя, пол, возраст, страны), потом путь от 0 до 100 %. HP — прогноз модели по ответам, данным к этому месту; вопросы впереди считаются ответами среднего ровесника, поэтому старт равен среднему для пола, возраста и страны, а финиш — прогнозу отчёта (`npm run test:journey`). Ответы — карты, их эффект скрыт до розыгрыша. Привал после каждого блока даёт реликвию за прохождение блока, а не за «хороший» ответ. Мир нарисован кодом: горы с параллаксом, небо меняется от блока к блоку, на финише вершина. Звуки синтезируются Web Audio и выключены, пока человек их не включит.
- **Стиль 2, «Переписка»** (`src/features/chat-quiz`). Вопросы задаёт черепаха Ала, ответы — кнопки быстрых ответов, на каждый ответ короткая реплика и сдвиг прогноза. На наследственности, диагнозах и анализах реплики нейтральные.
- **Стиль 3, «Копилка лет»** (`src/features/touch-quiz`). Банка наполняется годами, резерв лежит рядом. Пять вопросов отвечаются действием: тарелка с порциями, бокалы за неделю, часы сна, шаги, пульс, сосчитанный касаниями за 15 секунд (можно выбрать из вариантов). Под каждым действием видно, какой ответ из анкеты из него получился.

## Скорость

- `scripts/compile-hints.mjs` (шаг `build:pages`) ставит первой строкой скриптов подсказку `allFunctionsCalledOnLoad`: Chromium компилирует их в фоновом потоке. Для других браузеров это комментарий.
- Первая раскладка размечает один экран (`content-visibility` в `site.css`), остальные блоки домеряются по одному после загрузки (`LAID_OUT` в `layout.tsx`). При возврате, перезагрузке и переходе по якорю страница размечается сразу, иначе позиция прокрутки уезжает. Работает только там, где есть `overflow-clip-margin`, иначе обрезались бы рамки фокуса.
- Пустое состояние отчёта и результата лежит в HTML. Если ответы сохранены, до первой отрисовки его заменяет строка ожидания (`SAVED` в `layout.tsx`).
- Проверяя вёрстку или axe, отключайте отложенную разметку (`content-visibility: visible`), иначе проверка пройдёт по неразмеченному тексту.
- Мерить Lighthouse на свободной машине, минимум пять прогонов, и смотреть `benchmarkIndex`: ниже 1500 цифры занижены.

## Вопросы

Темы повторяют факторы теста kamalama.org, плюс силовые упражнения и сладкие напитки. Формулировки, варианты и тексты свои, без привязки к одной стране: ммоль/л и мг/дл рядом, рост и вес в метрических единицах или в футах и фунтах, служба спасения без единственного номера. Страна за последние 10 лет подставляется по IP-адресу (`shared/lib/country-by-ip.ts`: api.country.is, запасной get.geojs.io), её можно сменить. Перед анализами крови есть развилка: без результатов четыре вопроса пропускаются.

## Тест для питомцев

Кнопка «Пройти тест» в шапке ведёт на `/start`: выбор «Себя» или «Питомца». Тест для кошки или собаки живёт на `/pet/test` (15 вопросов для кошки, 16 для собаки), отчёт на `/pet/report`, описание факторов и источники на `/pet`. Ответы хранятся отдельно (localStorage, ключ `uzak-pet-v1`), история проверок общая для всех питомцев.

| Путь | Что там |
| --- | --- |
| `src/entities/pet/model/factors.ts` | Вопросы, варианты и отношения рисков для кошек и собак |
| `src/entities/pet/model/engine.ts` | Модель Гомперца–Мейкхема по группам (кошки, собаки четырёх размеров), калибровка по когортам, возраст по-человечески |

Проверка модели питомцев: `npm run test:pet`.

## Модель

1. **Исходная кривая**: таблица смертности ВОЗ за 2023 год (сглажена, после 85 продолжена по наклону Гомперца). Для 35 стран с годом войны, бедствия, спада или сломанной кривой по возрастам взят 2019 год, правило записано в `scripts/life-tables.mjs`. Прошлая и будущая страны смешиваются: прошлая весит половину в начале и уходит за 15 лет.
2. **Прогресс**: будущая смертность снижается на 1% в год во всех странах. Это допущение.
3. **Ответы**: каждый вариант несёт отношение рисков смертности от всех причин из метаанализа. Похожие факторы объединены в кластеры (тренированность, тело, питание, отношения и настроение, сахар): сильнейший эффект идёт целиком, остальные на 50, 30, 20 и 10%. Изменяемые факторы проходят мягкий потолок, наследственность и диагнозы добавляются поверх.
4. **Сверстники**: итог сравнивается со средним риском людей того же пола и возраста в стране пользователя. Семь групп показателей взяты у ВОЗ по странам, остальные доли повторяют образец Кыргызстана и для других стран приблизительны. Где у страны нет показателя, стоит медиана региона ВОЗ.
5. **Возраст**: относительные риски полные до 55 лет и слабеют вдвое к 80 (курение и вес в старости влияют слабее).
6. **Дорога и мотоцикл**: постоянная добавка к годовому риску за вычетом средней, с поправкой на смертность на дорогах страны.

Национальная статистика может отличаться от ВОЗ. Пример: в Кыргызстане таблицы за 2023 год совпадают в 30–69 лет (до 8%), а с 70 национальная даёт смертность выше у мужчин в 2,6–4,5 раза, с 75 у женщин примерно в 1,8 раза. Причина не установлена, наш прогноз оптимистичнее национального.

Отношения рисков взяты из публикаций (`sources.ts`), пересчитаны под варианты ответов или оценены. Врачебной проверки не было. Распространённость взята из опроса ВОЗ STEPS 2023 по Кыргызстану, переписи 2022 года, данных о дорогах и GLOBOCAN. Где данных нет, доли оценены и помечены `estimate` в коде.

Сверка 22 ноября 2026: 71 ссылка из 75 найдена в PubMed, у них сверены авторы, название, журнал, год и страницы. Цифры в текстах факторов сравнены с аннотациями, часть с открытыми полными текстами. Не сверены: полные тексты большинства статей, два отчёта вне PubMed (NHTSA 2015, книга данных STEPS) и выводы, которых нет в аннотациях. Коэффициенты, пересчитанные под варианты ответов, остаются оценкой. Коэффициенты модели питомцев подправлялись, пока проверки не сошлись, поэтому её тесты тоже не являются независимой валидацией.

## Что проверить перед запуском

1. **Вычитка врачом или эпидемиологом**: отношения рисков в `factors.ts`, особенно новые вопросы (рак, анализы, мышечная сила, отношения) и бездымный табак.
2. **Доли с пометкой `estimate`** в `population.ts`: сон, шаги, силовые, переработанное мясо, анализы, СРБ, омега-3, настроение. Заменить, если появятся местные данные.
3. **Вычитка носителями**: кыргызский целиком (в первую очередь медицинские термины и фразы об экстренной помощи), английский по возможности.
4. **Службы спасения**: на страницах «Напряжение» и «Это не диагноз» названы 112, 911 и 103 как примеры.
5. Название «Узак Өмүр» рабочее: меняется в `src/shared/config/site.ts`.

## Проверки

- `npm run test:model`: проверок 64. С опубликованными цифрами сравнивается около десяти, остальные следят за порядком эффектов и целостностью данных. Допустимые диапазоны заданы после первых прогонов модели, поэтому это защита от поломок, а не независимая валидация.
- `npm run test:game`: 22 проверки логики квестов. `npm run test:e2e:game`: 29 сценариев в браузере.
- `npm run test:journey`: 7 проверок HP «Пути героя» против модели. `npm run test:e2e:styles`: 26 сценариев выбора стиля и полных проходов трёх стилей.
- `npm run test:e2e`: 69 проверок в браузере. Полный проход, кнопки браузера, правка ответов, страна по IP и её сбой, ползунки, имя, тест питомца.
- `npm run test:e2e:locales`: 52 проверки. Выбор языка, все страницы трёх языков на 320, 375 и 1280 px, полный проход обоих тестов, непереведённые тексты, буквы ө, ү, ң.
- axe-core (WCAG 2.2 AA и best practices): 0 нарушений на 318 прогонах страниц, три языка, 1440 и 375 px.
- Hallmark `sloplint --render`, главная: 0 FAIL на русском и кыргызском. На английском одно ложное срабатывание правила 58 (считает закрытые ответы FAQ и только латиницу), записано в `site.css`.
- Lighthouse 23 ноября 2026, локальная копия без сжатия, мобильная скорость, медиана пяти прогонов: 100 на 37 страницах из 39 (13 типов, три языка), 99 на `/pet` и `/ky/pet`. Все четыре категории проверены на восьми страницах, мобильный и десктоп: 100, кроме скорости `/pet` на мобильном (99).
